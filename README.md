# SOCKS5 URI Converter & Proxy Checker

Веб-приложение для валидации, преобразования прокси SOCKS5 в формат URI (`socks5://...`), генерации ссылок V2Ray (`socks://...#Страна - Пинг`), проверки пинга (TCP) и геолокации без ограничений, дедупликации и пакетного экспорта (TXT, CSV, JSON, ZIP).

---

## Возможности

- **Парсинг и нормализация**: поддержка форматов `IP:PORT:USER:PASS`, `IP:PORT@USER:PASS`, `USER:PASS@IP:PORT`, `IP:PORT`, `socks5://...` и др.
- **V2Ray экспорт**: автоматическая генерация ссылок с флагом страны и задержкой (`socks://...#🇫🇮Finland - 240ms`) для v2rayN, v2rayNG, Nekoray.
- **Фоновый чекер пинга и гео на сервере**: многопоточная TCP-проверка задержки и определение страны/города/провайдера без лимитов. Работает автономно в фоне.
- **Загрузка по внешней ссылке**: импорт списков напрямую из Pastebin, GitHub raw или сторонних API.
- **Разделение и экспорт**: скачивание в TXT, CSV, JSON, а также разделение на архивы ZIP с заданным количеством строк.
- **Быстрый фильтр**: кнопка «Оставить только онлайн» в один клик заменяет список только на рабочие прокси.

## Локальный запуск

### Требования
- **Node.js**: 18+ или 20+
- **npm** или **pnpm** / **yarn**

### Установка и старт

```bash
# 1. Клонировать репозиторий
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd socks5-converter

# 2. Установить зависимости
npm install

# 3. Запустить в режиме разработки
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

---

## Сборка для продакшена

```bash
# Сборка клиентской части и сервера
npm run build

# Запуск продакшен-сервера
npm start
```

---

## Деплой

- **Cloud Run / Docker**: приложение автоматически биндится на `0.0.0.0:3000` и готово к контейнеризации.
- **VPS / Сервер**: запуск через `pm2 start dist/server.cjs --name socks5-converter`.
